## Ulanzi TC001 Companion v1.0.9 💾✨

Release **v1.0.9** introduces the dedicated **Configuration Backup & Restore Engine** to the Hardware Setup tab, enabling seamless interoperability with **Ulanzi TC001 Evolved v2.7.0+** firmware. Users can now export their entire clock setup to a JSON file via Android Storage Access Framework and restore their configurations anytime with direct validation and immediate hardware EEPROM commits.

---

### ✨ What's New in v1.0.9

#### 💾 Native Configuration Backup & Restore Deck (Hardware Setup Tab)
- **1-Click Export to JSON**:
  - Pulls complete device settings snapshot from `/api/backup`.
  - Seamless Android Storage Access Framework (`CreateDocument("application/json")`) file picker saving `ulanzi_tc001_backup.json` to internal storage, SD card, or Google Drive.
- **Direct File Restore with Confirmation**:
  - Open document picker (`ActivityResultContracts.OpenDocument()`) for selecting any previously exported backup JSON file.
  - Interactive safety confirmation dialog warning that parameters will be applied to hardware memory.
  - Dispatches validated payload to `/api/restore` with instant acoustic feedback and status banner.
- **Status Banners**:
  - Real-time phosphor green / signal red visual confirmation banner with 1-tap dismiss button.

#### 🔄 Complete Hardware & Web Portal Parity
- Fully synchronized with Ulanzi TC001 Evolved firmware **v2.7.0+**.
- Exports and restores:
  - Multi-profile Wi-Fi settings (Slots 1–4).
  - Clock display modes, date formats, icon styles, text alignment, and seconds visibility.
  - 7-day weekday indicators with customized active, inactive, and weekend phosphor color palettes.
  - 9-screen carousel parameters, sequence ordering, rotation bitmask, and 8 transition effects.
  - Ambient photometry (LDR auto-brightness, day ceiling, night floor, quiet red night schedule).
  - Ambient retro screensaver style and auto-timeout.
  - Meteorological coordinates, city presets, crypto ticker symbols, YouTube credentials, and Home Assistant MQTT broker configuration.

#### 🏷️ Version Bumps & Documentation
- Bumped version to `v1.0.9` (`versionCode = 10`).
- Updated internal `AboutDialog` version strings and web portal parity matrix.

### 📲 Installation Instructions
1. Download `app-release.apk` to your Android device.
2. If prompted by Samsung Auto Blocker or Android Play Protect:
   - On Samsung One UI 6 / 7: Temporarily disable **Auto Blocker** in *Settings ➔ Security and privacy*.
   - On Google Play Protect: Select *More details* ➔ *Install anyway*.
