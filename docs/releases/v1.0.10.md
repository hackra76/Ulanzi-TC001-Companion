## Ulanzi TC001 Companion v1.0.10 ⏱️🛡️

Release **v1.0.10** synchronizes the ambient screensaver lifecycle and wake behavior with **Ulanzi TC001 Evolved v2.7.1** firmware, ensuring non-blocking carousel progression and immediate responsive clock wake-ups.

---

### ✨ What's New in v1.0.10

#### ⏱️ Screensaver Lifecycle & Wake Synchronization
- **Responsive Screensaver Exit**: Tapping **■ Exit Screensaver** in the Ambient Screensaver Deck now sends an immediate deactivation signal (`/api/screensaver?action=stop`) and automatically shifts the active screen from Screen 8 (`APP_SCREENSAVER`) back to primary Clock mode (`APP_CLOCK`).
- **Synchronized Active App State**: Ensures the device status and preview immediately reflect waking from ambient mode without requiring manual app-switching.
- **Parity with Firmware v2.7.1**: Fully compatible with the non-blocking carousel auto-rotation and manual Web Portal screensaver testing controls in firmware v2.7.1.

#### 💾 Configuration Backup & Restore Engine (v1.0.9 Parity)
- Full support for native JSON backup export and direct restore to the device via Android Storage Access Framework.

#### 🏷️ Version Bumps & Documentation
- Bumped version to `v1.0.10` (`versionCode = 11`).
- Updated internal `AboutDialog` and hardware parity definitions.

---

### 📦 Asset Binaries
- **`app-release.apk`**: Production release APK signed with APK Signature Schemes v1 + v2 + v3.
- **`app-release.aab`**: Production Android App Bundle for Google Play Console / testing tracks.

### 📲 Installation Instructions
1. Download `app-release.apk` to your Android device.
2. If prompted by Samsung Auto Blocker or Android Play Protect:
   - On Samsung One UI 6 / 7: Temporarily disable **Auto Blocker** in *Settings ➔ Security and privacy*.
   - On Google Play Protect: Select *More details* ➔ *Install anyway*.
